# Typdy Starter Kit for PHP

[![Static Badge](https://img.shields.io/badge/honeystone-fa6900)](https://honeystone.com)

Our starter kits are tailored solutions for each platform, unlike the simple API
wrappers offered by other vendors. The [typdy](https://typdy.com) starter kit
for PHP provides repositories and Eloquent-like models corresponding to your
collections and blueprints.

This starter kit wouldn't be possible without the hard work of the many open
source package developers and contributors on which it is built.

_This package is jointly maintained by
[Honeystone](https://github.com/honeystone) and [typdy](https://typdy.com)._

See the [quickstart guide](https://typdy.com/docs/starter-kits/php) for
